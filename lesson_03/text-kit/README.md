# Text Kit

Учебный проект для демонстрации разделения монолитного файла на модули.

## Назначение
Программа выполняет базовые операции со строками, датами, числами и проверяет данные (почта, телефоны, пароли).

## Дерево проекта
```

text-kit/
├── app/
│   ├── __init__.py
│   ├── main.py           # Точка запуска, константы и функция main()
│   ├── services/
│   │   ├── __init__.py
│   │   ├── statistics.py # Расчёты по числам (среднее, медиана и т.д.)
│   │   └── validation.py # Проверка данных (почта, телефоны, пароли)
│   └── utils/
│       ├── __init__.py
│       ├── strings.py    # Работа со строками
│       └── dates.py      # Работа с датами
├── tests/                # Модульные тесты
└── README.md

```
