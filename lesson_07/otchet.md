# Практическая работа №7

## Документирование программного кода

### Цель работы

Изучить документирование Python-кода с помощью docstring.

### Основные задачи

1. Изучить назначение строк документации (docstring).
2. Рассмотреть документирование функций и модулей.
3. Описать назначение функций.
4. Указать параметры и возвращаемые значения.
5. Ознакомиться с ролью документации при сопровождении проекта.

### Вывод

Документирование помогает быстрее понимать назначение программного кода, упрощает его поддержку и дальнейшее развитие.
