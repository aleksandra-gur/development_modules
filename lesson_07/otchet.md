# Практическая работа №7

## Документирование программного кода

### Цель работы
Изучить принципы документирования Python-программ с помощью docstring.

### Основные этапы
1. Изучены строки документации Python.
2. Рассмотрено документирование функций.
3. Добавлены описания назначения функций.
4. Рассмотрены параметры и возвращаемые значения.
5. Изучена роль документации при сопровождении проекта.

### Вывод
Документирование помогает разработчикам быстрее понимать назначение функций и модулей, облегчает поддержку и дальнейшее развитие программного проекта.
