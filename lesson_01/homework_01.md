# Практическая работа №1

## Тестирование интернет-магазина Ozon

### 1. Основные пользовательские действия

1. **Поиск товара.** Пользователь вводит название товара в поисковую строку. Ожидаемый результат: отображается список подходящих товаров.
2. **Добавление в корзину.** Пользователь выбирает товар и нажимает «В корзину». Ожидаемый результат: товар появляется в корзине.
3. **Оформление заказа.** Пользователь переходит в корзину, проверяет заказ и нажимает кнопку оформления. Ожидаемый результат: заказ успешно оформлен.

### 2. Возможные ошибки

- Отсутствует подключение к интернету — товары не загружаются.
- Пользователь повторно нажимает кнопку оформления — возможна повторная отправка заказа.
- Не заполнено обязательное поле — система должна показать сообщение об ошибке.

### 3. Тестовое окружение

- Операционная система: Windows 11.
- Браузер: Яндекс Браузер.
- Язык программирования: Python 3.
- Редактор кода: Visual Studio Code.
- Система контроля версий: Git.

### 4. Вывод

В ходе работы рассмотрены основные пользовательские сценарии интернет-магазина Ozon, определены ожидаемые результаты действий и возможные ошибки. Составлены примеры проверок для основных функций сайта.
