# Практическая работа №5

## Тема: Аннотации типов в Python

### Цель работы

Изучить аннотации типов и научиться применять их в программном проекте.

### Основные задачи

1. Изучить аннотации параметров и возвращаемых значений функций.
2. Научиться указывать типы переменных и коллекций.
3. Использовать типы `str`, `int`, `float`, `bool`, `None` и составные типы.
4. Добавить аннотации типов в проект «Отчёт кафе».
5. Проверить код с помощью анализатора типов mypy и тестов pytest.
